1. Dynamic Inventory (AWS)

    - Dynamic inventory requires the Python libraries `boto3` and `botocore`.
    - These libraries allow Ansible to communicate with AWS APIs and discover EC2 instances dynamically.

    Install them using: ```sudo python3 -m pip install boto3 botocore```
